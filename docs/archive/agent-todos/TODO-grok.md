### M.6 `media/match.py` (or pool sub-api)

### M.7 `media/projects.py`
- **what:** save/load project, last path; **must** still mirror into session pool state on save (current behavior).

## Explicit non-goals / anti-patterns

1. Progressive classic `<script src>` split of `app.js` with top-level `let state` — **broken**. Modules only.
2. Putting `open_media` / thumb serving inside pure `cache.py` — **import cycles**.
3. Claiming datamosh `dry_run` works before it exists.
4. Trusting root `TODO.md` or STATUS.md over the tree.
5. Running `tools/rename_appjs.py` as “cleanup.”
6. Blocking CivitAI on full CSS/JS modularization.
7. Converting all engines to Filters in one commit.
8. Changing on-disk media cache layout without a migration note.
